# Módulo A · Mini Projetos · Planetário Estrela Guia (revisão)

Projeto pronto de revisão para o Estadual SP Skills 2026 (#17 Tecnologias Web). 9 tarefas (A1-E a C3-H), 15,00 pontos, de 3 a 5 vezes mais trabalhoso que o simulado de Jacareí.
Elaborado por Raul Porto Lopes (Avaliador).

| Arquivo | Para quem | O que é |
|---|---|---|
| Projeto_Teste_Modulo_A_Planetario.pdf/.docx | competidor | enunciado |
| assets_planetario/ (e .zip) | competidor | HTML travado, imagens, dados, arquivos de teste e vídeos de referência (Design.mp4 junta todos) |
| solucao-comentada/XXX_modulo_a/ (e .zip) | estudo | solução completa e comentada, com página índice e README nas tarefas C |
| solucao-comentada/Resolucao_Comentada_Modulo_A_Planetario.pdf | estudo | ideias-chave de cada tarefa e erros comuns |
| Guia_Avaliador_Modulo_A_Planetario.pdf/.docx | avaliador | roteiro de teste de cada aspecto e roteiros numerados das tarefas C |
| CIS_Modulo_A_Planetario.xlsx | avaliador | ficha de avaliação (coluna O = nota obtida, Q = evidência) |
| gabarito-avaliador/postman/ | avaliador | coleções collection_c1e/c2m/c3h.json (ajustar baseUrl) |
| .fonte/ | manutenção | geradores dos documentos, vídeos e testes |

Para publicar a solução: copie solucao-comentada/XXX_modulo_a/ para o Apache (mod_rewrite ligado) e dê permissão de escrita aos JSON das tarefas C. Antes de rodar o Postman de novo, restaure os JSON a partir de assets_planetario/.

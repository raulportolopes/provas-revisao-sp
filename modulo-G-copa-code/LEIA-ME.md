# Módulo G – Copa Code (Team Challenge) – projeto pronto de revisão

Torneio interescolar de e-sports: as equipes se inscrevem (5 titulares + reserva, 14 a 19 anos), a organização faz o check-in das 8 primeiras, gera o chaveamento, lança os placares da melhor de 3 e projeta a chave no telão até a campeã. API em PHP com PDO e MySQL (banco pronto e normalizado) e front-end em Vue 3 + Vue Router sem build. Equipe de 3 a 5, 20 min de planejamento + 2h10 de desenvolvimento + pitch. 5,00 pontos (× 0,2 para a escala de Jacareí). Elaborado por Raul Porto Lopes (Avaliador).
